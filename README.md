# Radar de eventos · Lima

Eventos en Lima que suman como estudiante (charlas, talleres, hackathons, meetups técnicos, becas), sin conciertos ni fiestas. Fuentes: Luma, Eventbrite y Meetup. Se actualiza solo cada 3 h con GitHub Actions y se publica en GitHub Pages.

Local: `pip install requests && python eventos.py` → `site/index.html`.
