🔑 Conecta tu GitHub (una sola vez)

El botón le pide a GitHub que corra la actualización. Para que solo tú puedas hacerlo, necesita una llave tuya. Queda guardada solo en este navegador; en otro dispositivo (tu celular) repites este paso una vez.

  1. Abre crear llave en GitHub ↗.
  2. Nombre: Radar Lima - Linktree. Vencimiento: 1 año.
  3. Repository access → Only select repositories → radar-eventos-lima.
  4. Permissions → Repository permissions → Actions: Read and write y Contents: Read-only.
  5. Generate token, cópialo y pégalo aquí:
  • Enviando la orden a GitHub
  • En cola
  • Leyendo los Linktree y separando inscripciones
  • Publicando el radar

Tarda unos 3 minutos en total. Puedes cerrar la página: el proceso sigue en GitHub.
